# iLab Free

Вільне програмне забезпечення для шкільного цифрового реєстратора даних
**Register iLab** (плата STM32L152 + USB CH372B + Bluetooth Microchip BM77).
Замінює застарілу «Цифрову експериментальну систему», яка не працює на сучасних Windows.

Ліцензія **MIT**: безкоштовно для шкіл, гуртків та ентузіастів, можна змінювати й поширювати.

| Частина | Де | Що потрібно |
|---|---|---|
| 📱 **Android-застосунок** | [`android/`](android) | готовий `iLabFree.apk` у розділі **Actions** (див. нижче) |
| 🌐 **Веб-версія для телефона** | [`docs/`](docs) | Chrome на Android або Bluefy на iPhone, адреса GitHub Pages |
| 💻 **Програма для ПК** | [`desktop/`](desktop) | Windows / Linux, Python 3.10+; USB або Bluetooth |

## Можливості

- графіки в реальному часі; вбудовані датчики (світло, УФ, тиск, температура, вологість, пульс);
- 4 зовнішні порти з автоматичним розпізнаванням датчиків;
- підключення через USB або Bluetooth (без кабелю, логер на батарейках);
- інтервал вимірів від 0.2 с до 5 хв, збереження в CSV / Excel;
- на ПК також: калібрування, порівняння з еталоном, фон «міліметрівка».

## Android: як отримати APK

1. Вкладка **Actions** → останній запуск **Android APK** (зелена галочка).
2. Унизу, у розділі **Artifacts**, завантажте **iLabFree-apk** (zip) і розпакуйте `iLabFree.apk`.
3. Перешліть файл на телефон і встановіть (дозвольте «встановлення з невідомих джерел»).
4. Увімкніть логер → «Підключити» → дозвольте доступ до пристроїв поблизу.

APK збирається автоматично після кожної зміни в репозиторії.

## Протокол (коротко)

USB bulk (CH372, VID 4348 PID 5537) або Bluetooth (SPP / BLE «Transparent UART»,
сервіс `49535343-fe7d-…`, запис у `…8841…`, дані з `…1e4d…`).
Пакети `[тип][N][дані][сума]`, сума = Σ байтів 0..N−1. Через Bluetooth до кожної
команди додається `55 55 55 55 55`. Команди: `A0` підключення, `A5` датчики, `A2` старт,
`A3` розширений формат / останнє значення, `A4` стоп, `A1` відключення.
Подробиці: [`desktop/ilab/protocol.py`](desktop/ilab/protocol.py).

Протокол відновлено реверс-інжинірингом для сумісності з обладнанням, яке належить школі.
