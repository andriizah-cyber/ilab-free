# iLab Free

Вільна програма для цифрового реєстратора **Register iLab** (плата STM32L152 + USB-чип CH372B)
замість застарілої «Цифрової експериментальної системи». Для шкіл, гуртків та ентузіастів.
Ліцензія MIT: можна безкоштовно використовувати, копіювати й змінювати.

## Що вміє

- графіки в реальному часі для всіх датчиків;
- вбудовані датчики реєстратора: світло, ультрафіолет, тиск, температура, вологість, пульс;
- зовнішні порти 1–4: температура (за заводською таблицею), вологість, напруга, сирий АЦП;
- калібрування будь-якого каналу за 1 або 2 точками (зберігається між запусками);
- **порівняння з еталоном**: попередній дослід або файл CSV/Excel накладається пунктиром;
- фон графіків: світлий, «міліметрівка», темний; вісь часу в секундах, хв:с або за годинником;
- інтервал вимірів від 0.2 с (≈5/с) до 5 хв;
- збереження у CSV (для Excel з українськими налаштуваннями) і Excel (.xlsx з графіками);
- **Bluetooth** (без кабелю, логер на батарейках) або USB;
- автоматичне розпізнавання датчиків у портах (плата повідомляє ID датчика);
- демо-режим без плати для навчання й перевірки.

## Встановлення (Windows 10/11)

1. Встановіть **Python 3.10+** з python.org (позначте «Add python.exe to PATH»).
2. Двічі клацніть **install.bat**: він встановить потрібні пакети.
3. Драйвер (один раз на кожному комп'ютері): під'єднайте реєстратор, запустіть **Zadig**
   (https://zadig.akeo.ie) → *Options → List All Devices* → «USB Connection»
   (USB ID `4348 5537` або `1A86 5537`) → драйвер **WinUSB** → *Replace Driver*.
   (Лише для USB. Для Bluetooth драйвер не потрібен — див. нижче.)
4. Запуск: **start.bat** (або `py run.py`). Без плати: **demo.bat** (`py run.py --demo`).

Linux: `pip install -r requirements.txt`, потім `sudo python3 run.py`
(або додайте udev-правило для 4348:5537).

## Bluetooth

1. Увімкніть логер (живлення від батарейок).
2. Windows: *Параметри → Bluetooth → Додати пристрій → Bluetooth* → виберіть логер
   (PIN, якщо спитає: 0000 або 1234). З'являться два COM-порти «через Bluetooth».
3. В iLab Free у списку ліворуч від «Підключити» виберіть **Bluetooth COMx** (програма
   ставить потрібний порт першим) → «Підключити». Перше з'єднання може тривати 5–10 с.

## Як користуватися

1. **Підключити** → дочекатися «Підключено».
2. Ліворуч відмітити потрібні канали; для портів 3 і 4 вибрати тип датчика.
3. **▶ Старт** — запис, **■ Стоп** — зупинка.
4. **Зберегти CSV / Excel** — експорт таблиці відмічених каналів.
5. **Калібрування** — канал → «взяти поточне» → ввести еталон → «Застосувати».
6. **Порівняння**: «Поточний → еталон» (або «З файлу…» для збереженого досліду),
   потім новий «▶ Старт» — еталон лишається на графіках пунктиром.

## Відомі обмеження (версія 0.3)

- Одиниці світла й УФ — умовні (сирі значення плати). Вологість у портах потребує калібрування.
- Плата передає дані раз на секунду (код частоти A8 на USB-потік не впливає).
  Інтервали ≥ 1 с — проріджування потоку; 0.2–0.5 с — опитування A3; максимум плати ≈ 5 вимірів/с (перевірено).

## Протокол (для розробників)

USB bulk, EP 0x02 OUT / 0x82 IN, пакети `[тип][N][дані][сума]`, де сума = Σ байтів 0..N-1.
Команди: `A0` підключення, `A5` датчики, `A8 xx` частота, `A2` старт, `A3` останнє
значення / розширений формат, `A4` стоп. Відповіді: `B0`, `B2` (дані: 8×u16 АЦП портів +
6×u32 вбудованих: світло, T×10, RH×10, УФ, тиск, пульс;
порти 1–4 по 2×u16 з байта 3 розширеного пакета), `B3`, `B5` (інформація про датчик).
Bluetooth (BM77, SPP): ті самі пакети, але до кожної команди додається `55 55 55 55 55`;
дані йдуть потоком байтів. `A1` — відключення. `B5` приходить для всіх портів 1–14
(1–4 зовнішні, 9–13 вбудовані, 14 — пульс) з ID, назвою (GBK) і одиницями.
Подробиці у `ilab/protocol.py`, тести на реальних пакетах у `tests/`.
